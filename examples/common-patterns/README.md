# UPIC RC3 — Canonical common-pattern preview

These front/back SVG renders are generated by the UPIC reference PHP renderer with 12-character core design codes. Their SVG patterns come from Maker v1.17. View `index.html` to inspect each print.

| Hex | Pattern |
| --- | --- |
| `0B` | Small floral |
| `0C` | Large floral |
| `0D` | Leopard |
| `0E` | Lace look |
| `0F` | Stars |
| `10` | Camouflage |
| `11` | Plaid |

A `0E` lace-look **print** is independent from lace **fabric** or lace **edge trim**. These examples are generated outputs, not separate canonical source SVG definitions.
